Two cases I bring up most in interviews.

Kept short: what went wrong, what I did, and how it ended.

Office Wi-Fi that kept resetting itself

The workspace connection dropped every lunch hour because the old router kept resetting its own IP.

What I did
Set one device as the DHCP server with a fixed address, then switched the access points to forward traffic instead of handing out their own leases.
Result
Stable for two weeks of monitoring, with no drop reports during peak hours.

A user laptop that would not power on

The laptop died after a system update, with documents inside that had never been backed up.

What I did
Removed the disk, copied the data to a backup drive, and only then repaired the system boot.
Result
Data intact and the laptop booting normally the same day, so the user lost no files.
